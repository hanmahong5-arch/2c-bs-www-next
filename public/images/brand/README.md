## Mark decision

Referenced common 「商标 野牛」 patterns (front head / profile / letter hybrids).
Picked **U + horns** for a software company:

1. Still reads as **U** → LURUS / URUS / RUS peel stays legible
2. Horns carry the 野牛 trademark cue without a full animal face
3. Scales to 16–28px in the header; front-head marks muddy at that size

Front-head and profile studies kept for reference, not shipped in chrome.

# Brand assets

图画标是四枚金属标，字标是 LurusTech。旧的 U + 野牛角文件留在本目录，不再进页面。

| 文件 | 标 | 用在 |
|------|----|------|
| `marks/crystal.png` | 核 | 公司主标；见证、Memorus |
| `marks/bolt.png` | 裂 | Kova、Forge；出错页 |
| `marks/z-metal.png` | 金属 Z | Hub、Platform。只在能看清体积的尺寸 |
| `marks/z-flat.png` | 平面 Z | Switch、Lux；页眉与 favicon（≤32px 只用这一枚） |
| `hero-abstract-ridge.jpg` | — | 首页满幅背景，不是商标 |

两个 Z 是同一字母的两种规格。原图黑金属加金线，页面垫纸 `#F5F2E8`，深色模式不反相。

## 个人站的三层名字

LURUS / URUS / RUS 仍是个人项目地图上的分层，不是四枚标的名字。自助用平面 Z，环境里用核，底座里执行用裂、入口与账用金属 Z。

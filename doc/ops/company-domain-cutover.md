# 企业域名与备案切流

## 为什么现在必须动

`lurus.cn` 当前是**个人备案**（鲁ICP备2026000242号），官网内容是**企业产品站**。  
工信部规则：超出个人范围的网站内容，备案主体应为单位。这正是阿里云「已备案信息核查」的高发原因——再怎么改页脚，主体与内容仍可能被判定不一致。

目标：一次切到企业主体，避免个人 ↔ 企业来回改。

## 两条路（优先 A）

### A. 主体变更（推荐，少搬家）

在阿里云备案里把 `lurus.cn` 主体从个人改为 **硅知睿智能科技（烟台）有限公司**。

| 保留 | 要做 |
|------|------|
| `www` / `docs` / `hub` / `identity` / `releases` / `kova` 等全部子域 | 企业证照、法人/负责人核验、幕布照片等 |
| SEO、外链、邮件域名 | 公安备案同步改主体 |
| 代码几乎不动 | 页脚挂上企业备案号；JSON-LD 可恢复 `legalName` |

适合：域名已在用、品牌就是 Lurus。

### B. 新企业域名 + 整站搬迁（备选）

注册企业主体域名，重新企业 ICP + 公安备案，再搬内容。

**域名候选（按品牌优先）：**

1. `lurustech.cn` — 与 LurusTech 字标一致（首选新域）
2. `lurus.com.cn` — 若可注册
3. 公司拼音短域（如 `szri.cn`）— 仅当 1/2 不可用

**必须一起迁的对外面：**

| 面 | 现域名 | 新域示例 |
|----|--------|----------|
| 官网 | `www.lurus.cn` | `www.lurustech.cn` |
| 文档 | `docs.lurus.cn` | `docs.lurustech.cn` |
| 登录/身份 | `identity.lurus.cn` | `identity.lurustech.cn` |
| Hub | `hub.lurus.cn` | `hub.lurustech.cn` |
| 发布 | `releases.lurus.cn` | `releases.lurustech.cn` |
| 邮件 | `contact@lurus.cn` 等 | 同步 MX / 别名 |

旧域：ICP 仍有效期间做 **301 → 新域**；注销个人备案前确认新域已可访问且挂新号。

## 执行清单（不论 A/B）

1. **今天**：阿里云登录 → 打开核查单 → 按专员要求补材料；页脚只挂备案号（不公示个人姓名）。
2. **定路线**：优先申请 **A 主体变更**；被拒或周期不可接受再走 B。
3. **若走 B**：公司支付宝/对公注册域名 → 阿里云企业 ICP → 公安备案 → DNS → 镜像同发 → 改本仓 `SITE_URL` / Ingress Host / 文档站 CNAME。
4. **验收**：工信部可查新主体；首页底备案号可点；公安备案号一致；docs 与登录可跳。

## 本仓近期代码约定

- 页脚：**只挂** `鲁ICP备…号` + 公网安备链接，**不写个人姓名**。
- `legalName`：个人备案期间从 JSON-LD 去掉；企业主体落地后再写公司全称。
- 切新域时：集中改 `SITE_URL`、Ingress `Host()`、外链常量（`docs` / `identity` / `hub` / `releases`）。
